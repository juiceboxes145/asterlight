## Images and text

The website SVG logo and interface are original project artwork. The team illustration was generated using OpenAI image generation and is an artistic illustration, not a scientific image: https://chatgpt.com/.

App screenshots show the original interface and attributed NASA/IPAC SPHEREx data. No stock photographs appear in the current app or guide. Original project text and code received AI assistance. The PowerPoint uses Arial and Georgia without bundling font files. Its PDF and PNGs preserve the visual layout.
